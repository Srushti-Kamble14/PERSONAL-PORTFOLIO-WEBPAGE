<br>
A vibrant and modern personal portfolio website built to showcase my skills, projects, and resume. The site features smooth scrolling, GSAP animations, and responsive design using HTML, CSS, and JavaScript.


<hr>
🔗 FEATURES
<br>
<br>
• Beautiful and colorful UI<br>
• Smooth scrolling using [Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll)<br>
• Scroll-triggered animations via [GSAP](https://greensock.com/gsap/) <br>
• Fully responsive layout <br>
• Resume download option <br>
• Animated interface using GSAP <br>
• Functional contact form layout (UI only) <br>
